# Consent Folder

This folder is for storing consent-related files.

## Current Status

**consent.pdf**: Not yet uploaded

## To Upload

1. Create a PDF file named `consent.pdf` with your informed consent form
2. Place it in this folder: `jspsych_mentalsim/public/consent/`
3. The consent screen will automatically display this PDF

## Current Placeholder

The consent screen currently shows a placeholder message until you upload the PDF. After uploading, the PDF will be displayed in the center of the consent screen.

## PDF Requirements

- Format: PDF (Adobe Acrobat or compatible)
- Size: Keep under 5MB for best performance
- Content: Complete informed consent form with:
  - Study information
  - Purpose and procedures
  - Risks and benefits
  - Confidentiality guarantees
  - Voluntary participation statement
  - Contact information
  - Research participant rights
  - Consent checkbox/acknowledgment
